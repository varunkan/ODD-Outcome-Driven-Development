# odd

`setup.sh` runs `odd init` from this repository's `odd.py` and switches to a branch named `work`. Nothing else: the
method reaches the agent through the `AGENTS.md` that `init` writes. The opt-in Claude Code hooks are not installed,
so this arm measures the configuration every tool gets. The prompt is the ticket and the two common closing sentences.

`post.sh` runs `odd gate --recompute --base main` after the session. Its result is recorded beside the hidden-test
result, so "gate passed, hidden tests failed" can be reported as its own figure.

Not verified until the pilot: that a headless Claude Code session started with `--setting-sources project` reads the
root `AGENTS.md` when the repository has no `CLAUDE.md`.
