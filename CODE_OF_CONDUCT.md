# Code of conduct

Be respectful and assume good faith. Criticise ideas, code and measurements, never people. Harassment, insults and
personal attacks are not accepted in issues, pull requests or any other space of this project.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report a problem privately to the maintainers through the repository's **Security** tab ("Report a vulnerability"
reaches only them); it will be read and answered.
